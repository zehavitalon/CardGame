# 🎴 חפיסת 54 קלפי פוקר אוניברסליים (Universal Playing Cards Deck)

חבילת קלפי פוקר מקצועיים עם מספרים סידוריים (1 עד 54) בפינות הנגדיות הריקות (שמאל-למטה וימין-למעלה), המיועדת להדפסה המונית לכל משחק או אירוע.

## 📂 פירוט הקבצים בתיקייה:
1. **universal_print.html** / **universal_deck.html**:
   - 12 גליונות A4 סופיים מוכנים לדפוס (6 גליונות חזיתות + 6 גליונות גב בהיפוך מראה אופקי לחיתוך דו-צדדי).
   - 9 קלפים בגודל פוקר אמיתי (63.5 × 88.9 מ״מ) בכל גליון.
   - איורי וקטור אותנטיים של קלפי פוקר מסורתיים (מלכים, מלכות ונסיכים דגם Rouen / Bicycle).
   - ג'וקרים וקטוריים אותנטיים (קלף 53 שחור, קלף 54 אדום).
   - גב יוקרתי עם טבעת זהב וקוד QR ניטרלי.

2. **card_preview.html**:
   - תצוגה מקדימה אינטראקטיבית הכוללת את תמונת המוקאפ המאושרת וגלריית 54 קלפים חיה עם סינון לפי סדרות (תלתן, יהלום, לב, עלה, ג'וקר).

3. **universal_deck.json**:
   - קובץ נתונים מובנה של כל 54 הקלפים, מסודרים כרונולוגית (תלתן 1-13, יהלום 14-26, לב 27-39, עלה 40-52, ג'וקרים 53-54).

4. **cardmeister.js**:
   - מנוע וקטורי מלא ועצמאי לייצור קלפי משחק מקצועיים ללא תלות ברשת.
